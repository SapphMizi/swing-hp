# swing-ui

swing-hp の画面を作る・直す・レビューするときに使う。要件の正本は `docs/requirements.md`、プロダクトの前提は `PRODUCT.md`。

## 避けるもの

### 見た目

- 黒や濃紺の背景。このサイトはライトテーマだけで、ダークモードも作らない
- ぼかした光の円(`blur-3xl` など)、ノイズの重ね、装飾目的のグラデーション(区切り線を含む)
- `rounded-2xl` のカードを同じ大きさで並べるだけのレイアウト。カードの背景に大きく薄い番号を置く装飾
- `font-mono` と広い字間(`tracking-[0.3em]` 以上)を組み合わせた英字の小見出し
- `backdrop-blur` のすりガラス風ヘッダー
- 浮遊するパーティクル、写真がゆっくり拡大する Ken Burns、ふわっと出て逆再生されるスクロール演出
- CSS や SVG フィルターで作った「手描き風」の線。手描きの部品は、アイコンから起こした画像を使う
- 絵文字をアイコンの代わりに使う

### 文言

- 誇張した宣伝文句(「最高の」「圧倒的な」)、呼びかけと感嘆符(「一緒にジャズしよう!」)
- 確認していない事実(部員数、受賞歴、部員の声)

## SWING の方針

- 見る人の大半はスマートフォン。390px 幅を基準に作り、押せる要素は高さ 44px 以上、文字は 12px 以上にする
- 基準は部の SNS アイコン(`public/images/swing_logo.jpg`)。桃色の紙に色鉛筆で描いた手描きの絵
- 色は `src/styles.css` の `@theme` のトークンだけを使う。背景は `paper` 系、文字は `ink`。リンクとボタンは `pink-deep`。`teal`・`orange`・`yellow`・`green` は背景の面として広く塗ってよく、その上の文字は `ink` にする。バンドのテーマカラーは `src/lib/bands.ts` にある(Blue Spirits Jazz Orchestra が `blue`、Swing Arcade Orchestra が `red`、The New Wave Jazz Orchestra が `navy`)。バンドの略称は表示しない
- 手描きの部品(ロゴ、吹き出し、鍵盤、キャラクター)は `public/images/hand/` に置き、見出しやヒーローに部品として使う
- フォントは本文と見出しに Zen Maru Gothic、吹き出しや手書きの注記に Klee One
- 見出しは英字の大見出しに日本語のラベルを添える形(SNOW MIKU 2026 の「PICK UP / ピックアップ」が見本)。英語表示のときは英語だけにする
- 日付は付箋の形で示す。お知らせ一覧はこの形で揃える
- 演出は状態の変化か、手描きの線が引かれる程度に限る。1回だけ再生し、300ms 以内(ヒーローの写真のクロスフェード 700ms だけは例外)。`prefers-reduced-motion: reduce` ではすべて止める
- 本文のコントラスト比は 4.5:1 以上。`pink` と `blue` は `paper` 上で基準に届かないので、文字に使わない
- 375px 幅で横スクロールを出さない
- セクションの境目は `TornEdge`(ちぎった紙の縁)か `Keys`(鍵盤の帯)で区切る。直線や細い罫線で区切らない

## レビューの手順

1. `npm run dev` を起動し、対象のページを 390px(先に見る)と 1440px でスクリーンショットに撮る
2. `npx impeccable detect http://localhost:3000/<パス>` を実行し、検出を一覧にする
3. 「避けるもの」に当たる箇所を挙げる
4. 「SWING の方針」と `docs/requirements.md` に照らして、新入生がスマートフォンで見学と連絡の方法にたどり着けるかを確かめる
5. 問題ごとに、どの項目に当たるかと、読み手にどう不利かを伝える
